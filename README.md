# 即刻 · 图片与视频创作工作台

一个本地运行的 Seedance 视频与 Seedream 图片创作工作台。界面参考 OpenArt 的创作布局，使用深色背景与亮绿色（#AAFF03）主题，保留左侧会话记录、右侧聊天式生成结果。前端由 React、TypeScript、Tailwind CSS 与 shadcn/ui 构建。

## 启动

需要 **Node.js 20.19 或更高版本**（包含 npm）。下载或克隆项目，在项目根目录打开终端，首次运行先安装依赖：

```sh
npm ci
npm start
```

打开 <http://localhost:3000>。macOS 也可以双击项目中的 **启动.command**，启动后会自动打开网页；如无执行权限，先执行 `chmod +x 启动.command`。端口冲突时，macOS / Linux 可运行 `PORT=3002 npm start`；Windows PowerShell 可运行 `$env:PORT=3002; npm start`，也可直接在 `.env` 中设置 `PORT=3002`。

`npm start` 会先构建前端再启动服务。开发时使用 `npm run dev`，前端代码和样式变更会自动重新构建，刷新页面查看；服务端代码变更会自动重启。

## 配置密钥

打开左下角「工作台设置」，填写火山方舟 **ARK API Key**，保存后即可生成。请在方舟开通所选模型；是否有权限、额度和并发容量以账户实际状态为准。

也可以复制 `.env.example` 为 `.env`，在本机编辑：

```dotenv
ARK_API_KEY=你的真实密钥
ARK_MODEL=doubao-seedance-2-5-flash-261115
PORT=3000
```

页面保存的密钥优先于环境变量，以明文保存在服务端的 `.data/settings.json`（创建时指定权限 `0600`，Windows 上的实际访问权限由系统 ACL 决定），不会放入浏览器 localStorage，也不会通过状态接口返回。移除页面保存的密钥后，会回退到环境变量。已有系统环境变量优先于 `.env`；修改环境变量后需重启服务。

服务仅监听 `127.0.0.1`，校验 Host、Origin 与跨站请求，不用于公网部署。

本地运行不等于离线生成：提交后，本次提示词和参考图片会发送给火山方舟，结果从方舟返回的地址下载。本项目不提供模型权重或免费 API 额度，调用费用与账号状态由火山方舟管理。

## 创作流程

1. 在输入框上方选择「图片生成」或「视频生成」，再选择模型。
2. 输入提示词，可通过选择文件、拖拽、粘贴添加参考图片。图片生成必须填写提示词；视频可以只提供符合当前模式要求的参考图。
3. 图片可设置比例、分辨率、PNG / JPEG、背景和水印；视频可设置多图参考或首尾帧模式、比例、分辨率、时长、声音和水印。
4. 点击「生成图片 / 生成视频」，或按 `Enter` 直接发送；`Shift + Enter` 换行。中文输入法选词时不会发送。
5. 页面自动更新生成状态，图片支持放大预览与下载，视频支持播放与下载；结果会尝试自动保存到本机，保存失败时可手动「重新保存」。

每次生成使用当前提示词与参考图片。聊天记录用于组织创作，不会把之前所有文字自动拼入下一次请求。「再次创作 / 复用提示词」会带回原提示词、参考图片、模型及参数，修改后再提交。

同一会话支持交替生成图片和视频，切换类型时分别保留两类参数。图片结果下的「继续编辑」会把该结果的本地副本作为下一轮参考图，清空提示词，让你描述本轮修改；需要先保存成功，且文件小于 30MB。编辑默认使用实色背景，以改善多轮画面一致性，实际效果取决于模型。不会自动上传之前整段聊天。

左侧支持搜索、切换、重命名及删除会话。生成或保存中的会话不能删除，避免丢失任务追踪。删除会话只移除历史条目，参考图片及已经保存的图片、视频文件仍保留在磁盘中，不会自动清理。

## Seedream 5.5 图片生成

使用 `doubao-seedream-5-5-261028`，与视频共用已配置的 ARK API Key；账户需开通该模型。

- 支持文生图、单图编辑和最多 10 张参考图融合，每次输出 1 张图片。
- 分辨率：`1K`、`1.5K`、`2K`，默认 `2K`。
- 比例：自动、1:1、16:9、9:16、4:3、3:4、3:2、2:3、21:9。自动比例发送分辨率档位；明确比例使用官方像素尺寸表，不改写提示词。
- 格式：PNG、JPEG；背景：自动、实色、透明。选择透明背景时自动使用 PNG；切换为 JPEG 时会将透明背景改为实色。
- 参考图支持本地上传、拖拽和粘贴。宽高大于 14px、总像素不超过 3600 万、宽高比 1:16–16:1。网页支持 JPG、PNG、WEBP、GIF，单张小于 30MB。
- 5.5 不支持组图与流式图片输出。服务端调用同步 `POST /api/v3/images/generations`，在后台等待结果，并通过本地 SSE 更新页面。本地服务保持运行时，关闭页面不影响其继续处理。
- 图片请求超时或服务中断会标记为「结果需要确认」，不会自动重发。图片接口没有视频任务 ID，无法用视频轮询接口找回；需在方舟控制台核对请求记录。
- 返回的图片链接有效期为 24 小时；本地会自动保存 PNG / JPEG 原文件。保存失败时可下载原图或点击「重新保存」，该操作只重新下载，不会再次生成。

本次界面接入图片生成与连续编辑，未提供图层拆分、富文本 OCR 的操作入口。

## 模型与参数

依据 2026-11-17 的方舟官方文档配置。是否可调用取决于账户权限和官方服务状态。

| 模型 | 分辨率 | 时长 | 多图参考 | 音频 |
| --- | --- | --- | --- | --- |
| Seedance 2.5 Flash | 480p / 720p | 4–30 秒或自动 | 最多 10 张 | 支持 |
| Seedance 2.5 | 480p / 720p / 1080p / 4K | 4–30 秒或自动 | 最多 30 张 | 支持 |
| Seedance 2.0 | 480p / 720p / 1080p / 4K | 4–15 秒或自动 | 最多 9 张 | 支持 |
| Seedance 2.0 Fast | 480p / 720p | 4–15 秒或自动 | 最多 9 张 | 支持 |
| Seedance 2.0 Mini | 480p / 720p | 4–15 秒或自动 | 最多 9 张 | 支持 |
| Seedance 1.0 Pro | 480p / 720p / 1080p | 2–12 秒 | 不支持；可用首帧 / 首尾帧 | 无声 |
| Seedance 1.0 Pro Fast | 480p / 720p / 1080p | 2–12 秒 | 不支持；可用单首帧 | 无声 |

1.0 系列在当前官方列表中标记为「即将下线」，在菜单中也有标识。

切换模型时会自动修正不支持的分辨率和时长；如果已有图片超出新模型的数量限制，会提示先移除图片。2.5 系列首尾帧模式自动固定为 `ratio: adaptive`。1.0 系列请求不会发送不支持的 `generate_audio` 字段。

使用自定义接入点时，在设置的默认模型下拉框选择「自定义接入点…」，填写 `ep-...`，并选择该接入点实际使用的模型。接入点将出现在生成模型菜单里，沿用对应的能力限制。环境变量方式可同时设置 `ARK_MODEL=ep-...` 与 `ARK_MODEL_PROFILE=对应的官方模型ID`。

视频参考图支持 JPG、PNG、WEBP、GIF，单张小于 30MB，宽高分别为 300–6000px，宽高比 0.4–2.5。上传文件在本机保存，调用 API 时转为 Base64；本地含图片的总请求上限为 64MB。切换创作类型时会校验参考图尺寸与数量。视频界面专注文本及图片生视频，不提供参考视频、参考音频或视频编辑上传入口。

## 状态同步与本地文件

- `POST /api/generations`：本地服务创建记录，根据所选模型调用方舟图片或视频接口。
- 视频：服务端通常每 4 秒查询一次 `GET /api/v3/contents/generations/tasks/{id}`；网络错误或限流会退避重试。图片：等待同步生成接口返回，默认超时为 5 分钟，不轮询视频任务接口。
- `GET /api/events` 使用 SSE 推送本地记录的状态到浏览器，无需手动刷新。视频接口返回异步任务状态，图片接口返回最终图片；这里都不是逐帧媒体流，也不会伪造百分比进度。
- 本地服务保持运行时，关闭浏览器不影响后台处理；重启本地服务后会恢复已有视频任务 ID 的轮询。图片请求中断后的处理见上文。
- 创建请求断线时不会自动重复生成。仅视频可从方舟控制台查到任务 ID 后使用「恢复追踪」。
- 视频成功后从官方返回地址下载到本机，支持 HTTP Range 播放和下载。官方临时视频 URL 有效期为 24 小时；本地副本可长期保留。

```text
.data/
  settings.json      # 本机配置和密钥，不进入版本控制
  history.json       # 会话、任务、参数与素材索引
  uploads/           # 上传的参考图片
  videos/            # 自动保存的视频
  images/            # 自动保存的 PNG / JPEG 图片
```

图片和视频的本地保存上限分别为 50MB、500MB。超过限制或下载失败时，会保留远程地址和错误提示；远程地址过期后无法保证还能找回文件。

`.data/`、`.env` 和 `.env.*` 已加入 `.gitignore`，仅保留不含密钥的 `.env.example`。输入中的草稿保存在当前浏览器，不包含 API Key。`.data/history.json` 包含提示词、素材名称、任务记录和可能带签名的结果链接，上传素材与生成结果也属于本机私有数据。

## 发布源码

只提交源码、锁文件、文档和 `.env.example`。不要上传 `.data/`、真实环境配置、日志、私人截图或媒体文件；直接打包整个工作目录或通过网页上传文件不会自动遵守 `.gitignore`。Git 初始化后可使用 `git status --short --ignored` 和 `git diff --cached` 检查待提交内容。忽略规则不会移除已被 Git 跟踪的文件。

## 常见问题

- `AccountOverdueError`：方舟返回账号欠费。处理 API Key 所属账号的欠费并恢复服务后，复用提示词重新提交。
- 图片结果需要确认：请求超时或服务中断，先核对方舟记录，不要连续重试。
- 视频无法在浏览器播放：部分高分辨率输出使用 H.265/HEVC，可下载原文件并用兼容播放器打开；本项目不进行转码。

## 代码

- `server/index.mjs`：启动、环境变量、监听与退出。
- `server/app.mjs`：本地 API、方舟调用、文件持久化、轮询、SSE 和媒体下载。
- `public/models.js`：前后端共用的模型能力表。
- `src/App.tsx`：页面布局、会话操作与任务恢复弹窗。
- `src/components/`：侧边栏、输入区、设置弹窗与图片 / 视频结果卡片。
- `src/components/ui/`：shadcn/ui 官方组件源码，包含 Sidebar、Select、Checkbox、Dialog、AlertDialog、DropdownMenu、Popover、Tooltip、Button、Card 等。
- `src/hooks/use-studio.ts`：模型切换、上传、草稿、任务提交与 SSE 状态同步。
- `src/styles.css`：Tailwind CSS 与亮绿色主题变量，桌面及移动端共用。
- `components.json`：shadcn/ui 配置，可继续添加或调整组件。
- `scripts/`：前端构建和开发监听；产物输出到 `public/build/`。
- `test/`：独立的本地接口测试。

前端资源均在本地构建，无需在线加载组件或字体。原有会话数据及浏览器草稿与新版兼容。shadcn/ui 组件的 MIT 许可见 `THIRD_PARTY_NOTICES.md`。
